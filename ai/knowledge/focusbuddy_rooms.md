# Study rooms

## Creating a room
Open Rooms and choose Create Room. A room name must be 3 to 50 characters long. Tick the join code option to get an 8-character code that others can use to join, and an invite link you can copy and share. The person who creates a room is its owner and is added as a member automatically.

## Public and private rooms
A room without a password is public: it appears under Public Rooms and anyone logged in can join it with one click. Setting a password when you create the room makes it private: it is not listed publicly, and people need both the join code and the password to get in.

## Joining a room
To join a private room, choose Join with Code and enter the join code and the room password. To join a public room, open Rooms and press Join on the room card. Joining the same room twice does nothing; you stay a single member.

## Leaving or deleting a room
Members can leave a room at any time from the room page. The owner cannot leave their own room; the owner can delete the room instead, which removes it for everyone.

## Managing members
Only the room owner can remove (kick) a member, and the owner cannot be kicked. The members list shows who is online right now and when others were last seen.
